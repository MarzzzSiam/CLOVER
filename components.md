# 🧩 CLOVER — Project Components

This document contains the complete list of hardware components used to build **CLOVER — Autonomous Sanitizing Rover**.

---

## ⚡ Electronic Components

| Component                       | Quantity | Purpose                                                    |
| :------------------------------ | :------: | :--------------------------------------------------------- |
| **ESP32 Dev Kit**               |     1    | Main microcontroller with Wi-Fi connectivity               |
| **ESP 30P Dev Expansion Board** |     1    | Provides convenient interfacing for sensors and components |
| **HC-SR04 Ultrasonic Sensor**   |     1    | Detects obstacles in the rover's path                      |
| **MQ-2 Gas Sensor**             |     1    | Detects smoke and combustible gases                        |
| **L298N Motor Driver**          |     1    | Controls the four gear motors                              |
| **Relay Module**                |     1    | Controls the water pump                                    |
| **Buzzer**                      |     1    | Provides an audible alert when an object is detected       |
| **5V DC Water Pump**            |     1    | Dispenses sanitizing liquid                                |
| **Servo Motor**                 |     1    | Controls the direction of the spray                        |
| **ICR18650 Li-ion Battery**     |     5    | Power source for the rover                                 |

---

## 🛞 Mechanical Components

| Component                     |   Quantity  | Purpose                         |
| :---------------------------- | :---------: | :------------------------------ |
| **Chassis Board with Wheels** |      1      | Main platform for the rover     |
| **TT Gear Motors**            |      4      | Provides movement to the rover  |
| **HC-SR04 Mounting Bracket**  |      1      | Mounts the ultrasonic sensor    |
| **Battery Holders**           | As required | Holds and secures the batteries |

---

## 🔌 Wiring & Miscellaneous

| Component                                  | Purpose                                   |
| :----------------------------------------- | :---------------------------------------- |
| **Jumper Wires (M-M, F-M, M-F)**           | Electrical connections between components |
| **Pipe / Tubing**                          | Transfers sanitizing liquid from the pump |
| **Power Switch**                           | Turns the rover power on/off              |
| **Screws & Fasteners**                     | Secures components to the chassis         |
| **Miscellaneous Connectors & Accessories** | General assembly and wiring               |

> **Note:** Component quantities may vary depending on the final hardware configuration and assembly requirements.
